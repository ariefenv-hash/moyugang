## Description:

Guides agents toward Chinese literati painting aesthetics using style tokens, anti-tokens, application rules, and evaluation criteria for brush-as-writing visual work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[johnnyzijianwu](https://clawhub.ai/user/johnnyzijianwu)

### License/Terms of Use:

MIT-0

## Use Case:

Artists, designers, and agents use this skill to generate or critique visual-art concepts in the Song-to-Qing Chinese literati painting tradition. It helps preserve calligraphic line quality, ink gradation, negative space, inscription integration, and scholarly restraint.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can steer visual-art work toward a specific Chinese literati and calligraphic painting aesthetic even when that style is not desired.

Mitigation: Install or enable it only for tasks where this aesthetic direction is intended.

Risk: Generated or evaluated work may overstate authenticity if the agent applies style tokens mechanically.

Mitigation: Review outputs for calligraphic energy, active negative space, inscription fit, and scholarly restraint using the included evaluation criteria.
