# 墨韵战纪：风雅篇

以宣纸为局、以墨为刃的水墨风火柴人动作游戏。扮演诗剑剑仙，穿行五折山水之间，以笔意御剑，以字诀出招。

基于 React + Vite + Canvas 构建，支持安装为 PWA 并完全离线游玩。

## 游戏特性

- **五折战役 + 无尽卷** —— 五幕水墨篇章各有独立场景与敌阵，外加挑战极限的无尽模式
- **剑仙技能体系** —— 四主动技能与终结大招，矢量武器系统与专门调校的打击感（顿帧、斩击闪白、墨滴飞溅）
- **字诀手势识别** —— 基于 Unistroke 算法的汉字笔划识别，在屏幕上书写字诀即可施放对应技法，附朱印评级反馈
- **四大趣味机制** —— 祝福、文房四宝、墨龙、墨滞，为战局注入变量
- **PWA 完整支持** —— 主屏幕安装、Service Worker 预缓存离线可玩、自动检测新版本并提供更新提示

## 操作方式

- 桌面端：键盘操控
- 移动端：滑动手势 + 字诀识别，完整手势操作

## 本地开发

```bash
# 安装依赖（亦可用 npm / pnpm）
bun install

# 启动开发服务器（默认 :3000）
bun run dev

# 类型检查
bun run lint

# 生产构建（产出含 sw.js 与 manifest 的 PWA 产物）
bun run build
```

## 技术栈

React 19 · Vite 8 · TypeScript 5 · Tailwind CSS 4 · Canvas 2D · vite-plugin-pwa（Workbox 预缓存）

## 目录结构

```
src/
  components/   # 界面组件（战斗、章节选择、祝福、成就等）
  utils/        # 渲染器、动画系统、手势/字诀识别、武器系统、音频
  data/         # 关卡与游戏数据
  assets/       # 字体与美术资源
scripts/        # 图标生成、字体子集化、冒烟测试等开发脚本
public/         # PWA 图标与静态资源
```
